# Deep Learning From Scratch

## Running local environment

1. Activate environment

   `source deep-learning-from-scratch/bin/activate`

2. Install package

   `pip install <package-name>`

3. Update requirements.txt

   `pip freeze > requirements.txt`

4. Deactivate environment

   `deactivate`

## Topics

1. Foundations

   - Linear Regression & Logistic Regression.

   - Loss Functions: Mean Squared Error (MSE) vs. Cross-Entropy.
   - Gradient Descent (Batch vs. Stochastic)
   - Optimizers

2. Multi-Layer Perceptron
   - Activation functions
   - Back propogation
3. Computer Vision (Convolutions)
4. Sequence Models
5. Transformers (Attention is All You Need)
6. Diffussion Models
7. Flow Matching
8. Protein Design
